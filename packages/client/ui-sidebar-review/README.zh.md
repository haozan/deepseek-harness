# @deepseek-ai/dsh-client-ui-sidebar-review

[English](README.md) | 中文

## 概述

将文件预览截图收进阅卷笔录。识别和编辑卡片文字，再按文件夹归类。导出时文件夹会成为章节标题。

<a id="use-this-package"></a>
## 使用此包

在「插件」中启用 **阅卷工作台**，然后点击左侧边栏的入口。在「从工作区新建」中选择目录后，会新建一条阅卷会话，快捷操作在输入框正上方。在已打开的阅卷会话中，点击同一工作区的「新会话」会新建一条独立的阅卷会话并显示这些快捷操作。「继续已有阅卷」按工作区显示有笔录或证据的阅卷。点击工作区继续最近一条有内容的阅卷，也可展开「其他阅卷记录」打开更早的笔录。已归档的阅卷会隐藏。阅卷资料保存在关联工作区内的 `阅卷数据` 文件夹。每份阅卷有一个 `review.json` 档案和 `screenshots` 截图目录。档案保存笔录、文件夹、排序、标色、证据和框选坐标。工作区内的原文按相对路径记录。换电脑时复制整个工作区，在已启用插件的新版桌面端重新选择该文件夹，首次关联会打开最近保存的阅卷。工作区外的原文保留原路径。AI 对话记录保存在桌面端配置中。

在对话栏上方点 **打开阅卷笔录** 或 **打开证据目录** 即可打开右侧边栏。文件在左，两个阅卷标签在右。需要放大时，可点击侧栏的 **全屏** 按钮。点 **让 AI 使用笔录**，即可在空白输入框中填入一段可编辑的提示词并聚焦。把括号里的内容换成指定文件夹或全部笔录，再写明任务，例如核对「合同履行／付款凭证」里的证据，或起草一份法律文书。已有草稿时，按钮会聚焦草稿。AI 会读取当前阅卷对话里的已保存笔录，文字不足时可以查看截图。遇到同名文件夹时，请提供完整路径。要查询较早的阅卷，可以从 **其他阅卷记录** 中打开，或在问题里指定。

在右侧边栏打开文件，点击 **截图进阅卷笔录**，然后在预览中拖动框选。松开后保存截图并打开使用同一框选图标的 **阅卷笔录** 标签页。按 Esc 可取消。空间足够时，截图后笔录会在文件预览旁打开。边栏较窄时，可以切换标签，也可以拉宽后继续截图。

点击提示为 **截图进证据目录** 的清单图标，框选的区域会保存到独立的 **证据目录** 标签页。点击证据截图可定位原文，点击原文框线可返回对应截图。

笔录截图按截取顺序出现在 **未归类**。**阅卷笔录** 是根节点。带托盘图标的 **未归类** 位于文件夹树最底部，与笔录顺序一致。在根节点行的 **⋯** 菜单中选 **新建文件夹** 可建立一级目录。自建目录行的菜单可新建子文件夹或重命名。阅卷栏较宽时，文件夹树与卡片并排。窄栏可通过列表上方的文件夹选择器切换。

点 **阅卷笔录** 可阅读大纲。文件夹名称是标题节点，缩进和细竖线表示卡片与子标题所属的章节。点击标题或左侧箭头可折叠或展开整个分支。每张卡片是一个叶子节点。正文为空时显示截图，点击截图可直接输入笔录。有正文时显示可编辑的文本框，文本框随内容增高。导出的 HTML 包含已折叠的章节。有其他章节和未归类卡片时，**未归类** 章节排在末尾。可在章节内拖动卡片排序，切换章节时将卡片移到对应文件夹即可。

用卡片左侧的拖动把手可以排序，也可以把卡片放到文件夹上。批量移动时，点 **多选** 并勾选卡片，再用 **移动到**，或把任一选中的卡片拖到目标文件夹。卡片会按当前顺序追加到目标文件夹。把手获得焦点时，也可以用上下方向键、Home 或 End 排序。

用文件夹 **⋯** 菜单里的 **上移** 或 **下移** 调整同级顺序。也可以拖动文件夹名称，或在名称获得焦点时用 Alt+↑ 或 Alt+↓ 逐项移动。文件夹会连同卡片和子目录一起移动。导出的章节沿用保存的文件夹顺序。

在自建文件夹的 **⋯** 菜单里选择 **删除文件夹**，确认后删除该文件夹及其子目录。其中的卡片会移到 **未归类**，截图、原文件链接和卡片正文都会保留。

卡片数量在最右侧对齐。使用鼠标时，菜单按钮在悬停、聚焦或菜单打开时显示。过长的目录标题会显示省略号，悬停或聚焦可查看全名。

阅卷栏较宽时，可用卡片工具栏上的面板图标收起或展开目录树。收起时，悬停图标可查看当前目录。拖动分隔线即可调整宽度，也可聚焦分隔线后按左右方向键。在当前阅卷栏再次展开时会恢复之前的宽度。

PDF、图片和文本预览会用红色细线显示当前文件已保存的截图框。点击卡片的 **定位来源** 可打开原文件并滚到对应的框，有分栏时会在另一栏显示。点击框线会滚到对应卡片，并短暂显示淡红高亮。点击重叠的框线可按截图顺序选择卡片。阅卷会自动展开卡片所在章节及其已折叠的上级章节。框内原文仍可选择和复制。旧截图、表格和 HTML 预览可通过 **定位来源** 打开原文件。定位框只显示在预览里。

悬停或聚焦卡片时显示工具按钮，触屏上始终显示。点 **识别文字** 可识别单张，点 **识别全部** 可处理当前列表里的待识别卡片。列表中的卡片都已有识别结果时，按钮显示 **已全部识别**。识别结果追加在已有文字后面。识别后，只要卡片仍有正文，按钮就会提示 **已识别**。清空正文或识别结果为空时，可再次识别单张卡片，也可使用 **识别全部**。点 **与 AI 交流** 会把完整正文和截图追加到当前对话草稿。全屏阅卷时也会让出对话区。可在对话输入框补充问题后发送。点 **修改颜色** 可用五种颜色之一在正文区域左侧画一条直线，也可清除标色。编辑时，标注色显示在焦点框左侧。

**自动 OCR** 默认开启。新截图保存到阅卷笔录后，视觉大模型会自动识别其中的文字。在阅卷工具栏关闭此开关可改为手动识别，设置保存在本机的应用配置中。关闭会跳过尚未发出的自动请求，已发出的请求可以完成。主动开启时会短暂提示视觉模型和 Token 消耗。悬停开关可再次查看提示。开启后从下一张笔录截图开始自动识别。

打开 **显示来源** 后，每张卡片开头会显示 `【文件名】`，去掉最后一个后缀。导出也跟随此开关。

点击 **导出**，选择 **图文模式** 或 **纯文字模式**，即可将整份笔录保存为独立的 HTML。**图文模式** 包含全部截图和文字。**纯文字模式** 会为没有识别出文字的卡片保留截图。文件夹按树形顺序成为章节标题，未归类卡片放在末尾。可用浏览器阅读或打印。归类、文字、颜色和卡片顺序保存在本机，重启桌面端后仍可查看。

<a id="back-up-and-move-a-review"></a>
### 备份和迁移阅卷

关闭或复制工作区前，等笔录保存完成。如果文件工具栏显示 **重试保存裁剪**，请在原文预览仍打开时重试。笔录和证据目录中的截图都保存在工作区的可迁移档案里。

保存完成后，将**整个工作区**复制到另一个磁盘或电脑。在目标电脑的阅卷工作台打开该文件夹，检查一张笔录卡片和一张证据截图，再点击各自的来源链接。保留一份独立备份。跨电脑使用同一个工作区时，请一次只用一个 Host 编辑。

每次替换 `review.json` 时，上一版已提交的清单保存在 `review.previous.json`。如果当前清单损坏，先退出桌面端，再单独复制一份工作区。在副本里将损坏的文件改名保留，并在同一个档案目录把 `review.previous.json` 复制成 `review.json`。打开副本，核对笔录和证据目录。恢复的是上一版清单。保留原工作区，以便找回之后的编辑或截图。

### 从源码目录加载插件

这个插件依赖匹配的桌面构建提供裁剪接口。在源码目录运行 `pnpm install --frozen-lockfile` 和 `pnpm run dev:desktop`。在该桌面构建的 **插件** 页中，用源码目录内 `packages/client/ui-sidebar-review` 的绝对路径安装并启用。保留该路径，方便日后升级。

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节</summary>

安装并启用后，插件加载文字识别服务和桌面客户端。文档预览提供可见正文的边界，框选关闭后 Electron 截取视口中选定的像素。工作区档案按内容哈希保存每张 PNG，并提交记录文件地址、文件夹、归属、顺序、正文、颜色和识别状态的清单。客户端打开档案时，会从 IndexedDB 导入符合条件的旧草稿和 PNG。旧摘录和备注会合并到同一个文本框，摘录在前。旧卡片已有摘录时视为已识别。旧小节标题会转为文件夹，明确排在各标题下的卡片会归入对应文件夹。其余截图保留在未归类中。

</details>

<a id="model-experience"></a>
## 模型体验

### 笔录问答

#### 模型看到的内容

[`review_transcript` 工具](src/review-tool.ts)在关联了已注册工作区的阅卷对话中可用。它从选定的阅卷档案读取已保存的文件夹、卡片文字和单张截图。文件夹列表和卡片列表按页返回。工具结果会将所读取的文字和图片附件引用记入会话日志。来源链接会打开工作区中的原文件。

#### Token 影响

读取文件夹和文字消耗所返回内容的输入 token。读取截图还会消耗图片 token，并要求当前对话模型支持图片。

#### KV Cache 影响

每次工具调用的结果都会进入对话历史。阅卷档案保存在磁盘上，后续读取会获取已保存的更改。

### 截图识别

#### 模型看到的内容

用户明确选择的截图和[转写指令](src/index.ts)。Host 在调用前把准确的输入记录在 `document-review/recognition-request` 会话事件中。模型路由、请求时限和输出 token 上限由桌面端配置指定。

#### Token 影响

每次识别发出一次独立的视觉请求，消耗图像及输入 token，并受配置的输出上限限制。

#### KV Cache 影响

辅助调用使用独立的消息列表。**与 AI 交流** 将完整正文和截图放入普通对话的草稿。发送时这些内容随问题一起进入对话。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>
- 问答的引用链接会打开工作区中的原文件。要定位已保存的裁剪框，请点击阅卷笔录里的对应卡片。
