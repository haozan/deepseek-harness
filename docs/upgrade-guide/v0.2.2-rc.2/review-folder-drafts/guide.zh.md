# 打开按文件夹整理的阅卷草稿

[English](guide.md) | 中文

## 变更

阅卷草稿用文件夹组织卡片。桌面端打开旧草稿时会将原有小节显示为文件夹。编辑并保存后，只支持小节的旧桌面端无法打开该草稿。新版桌面端把草稿、截图、证据和原文定位写入工作区内的 `阅卷数据` 文件夹。打开阅卷工作台时会把能匹配到当前工作区的旧截图和草稿复制进去。

## 迁移

1. 在新版桌面端打开会话，进入 **阅卷**。确认旧小节名称出现在文件夹列表中，截图、摘录和备注均可查看。
2. 如需在新版桌面端之外阅览笔录，在阅卷栏选择 **导出**，再用浏览器打开 HTML 文件。
3. 换电脑前确认工作区内出现 `阅卷数据`，再复制整个工作区。在目标电脑的阅卷工作台选择该文件夹，并检查已保存的笔录、证据截图和原文定位。上一版清单的恢复方法见[备份和迁移阅卷](../../../../packages/client/ui-sidebar-review/README.zh.md#back-up-and-move-a-review)。
